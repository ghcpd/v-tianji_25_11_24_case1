# Merino Warm-Layer E-Shop UI

A small, modern, accessible React + Vite TypeScript UI demonstrating a product grid for merino wool layers.

How to run:

```powershell
npm install
npm run dev  # starts dev server
npm run test  # runs both unit tests (vitest) and E2E tests (playwright)

To run unit tests with coverage (Vitest):
```
npm run test:unit
```

To run E2E tests (Playwright):
```
npm run test:e2e
```
```

Project structure:
- src: application code
- e2e: Playwright tests
- public/images: simple SVG placeholder images

All tests should pass using `npm run test`.
